# 📦 Proyecto PaqueteEnvio

Este proyecto simula el seguimiento de paquetes de envío utilizando programación orientada a objetos en C++.

## 🚀 Características
- Uso de clases (.h y .cpp)
- Uso de STL (vector)
- Validaciones
- Historial de estados del paquete
- Documentación con Doxygen
- Compilación con CMake

## ⚙️ Compilación

```bash
mkdir build
cd build
cmake ..
make
./ProyectoPaquete
